📖 Guide — Mini-Convertisseur TOSSARA v5

Ce convertisseur communique avec l'agent principal (Islam Agent Épistémique) via BroadcastChannel.

  1. Ouvrez Islam Agent Épistémique dans un autre onglet du même navigateur
  2. Vérifiez que le nom du canal est identique des deux côtés : tossara_agent_bridge
  3. Ajoutez vos fichiers (MP3, MP4, PDF, EPUB…) ou convertissez une sourate
  4. Cliquez Transférer tout — l'agent les reçoit et les affiche dans sa ☰ Biblio
  5. Dans l'agent, cliquez sur un élément de la biblio pour l'ouvrir ou l'écouter
Agent hors ligne ? Les éléments restent en biblio locale avec le statut "En attente". Ils seront envoyés dès que l'agent sera actif.
